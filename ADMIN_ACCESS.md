# 🔐 Как получить доступ администратора

## Способ 1: Через консоль браузера (быстрый способ)

### Для компьютера:
1. Откройте ваше приложение в браузере
2. Нажмите **F12** (или Ctrl+Shift+I / Cmd+Option+I на Mac)
3. Перейдите на вкладку **Console**
4. Вставьте эту команду:

```javascript
localStorage.setItem('nearme_admin', 'true'); location.reload();
```

5. Нажмите **Enter**
6. Страница перезагрузится и у вас появятся права администратора

### Для телефона:
1. Откройте ваше приложение в браузере
2. Откройте меню браузера (⋮ или ⋯)
3. Выберите **"Инструменты разработчика"** или **"DevTools"**
4. Перейдите на вкладку **Console**
5. Вставьте команду:

```javascript
localStorage.setItem('nearme_admin', 'true'); location.reload();
```

6. Нажмите **Enter**

---

## Способ 2: Через Application (более надёжный)

1. Откройте ваше приложение в браузере
2. Нажмите **F12** для открытия консоли разработчика
3. Перейдите на вкладку **Application** (или **Приложение**)
4. В левом меню найдите **Local Storage** → выберите ваш домен
5. Нажмите кнопку **+** для добавления новой записи
6. Введите:
   - **Key**: `nearme_admin`
   - **Value**: `true`
7. Обновите страницу (**F5**)

---

## Как использовать админ-панель

1. После получения прав администратора, в правом верхнем углу появится иконка **щита** 🛡️
2. Нажмите на неё для открытия админ-панели
3. В админ-панели доступны:

### 📊 Обзор
- Общее количество пользователей
- Пользователи онлайн в реальном времени
- Количество сообщений
- Количество лайков
- Активные чаты
- Новые регистрации за сегодня
- Последняя активность

### 👥 Пользователи
- Список всех пользователей
- Поиск по имени
- Просмотр детальной информации
- Статус онлайн/оффлайн
- Количество лайков
- Возможность заблокировать пользователя

### 💬 Сообщения
- Последние 50 сообщений
- Отправитель и получатель
- Время отправки
- Статус прочитано

### 📈 Активность
- Активность по времени (онлайн, за последний час, сегодня, за неделю)
- Топ-5 популярных пользователей
- Графики активности

---

## Как убрать права администратора

### Через консоль:
```javascript
localStorage.removeItem('nearme_admin'); location.reload();
```

### Через Application:
1. Откройте вкладку **Application**
2. Найдите **Local Storage** → ваш домен
3. Найдите запись `nearme_admin`
4. Нажмите на неё и нажмите кнопку **-** для удаления
5. Обновите страницу

---

## Быстрая команда для копирования

### Включить админ-доступ:
```javascript
localStorage.setItem('nearme_admin', 'true'); location.reload();
```

### Выключить админ-доступ:
```javascript
localStorage.removeItem('nearme_admin'); location.reload();
```

### Проверить статус:
```javascript
console.log('Admin:', localStorage.getItem('nearme_admin'));
```

---

## ⚠️ Важно

- Админ-доступ работает только на вашем устройстве
- Другие пользователи не видят админ-панель
- Для полноценной защиты нужна серверная аутентификация
- В будущем планируется добавить настоящую систему ролей
