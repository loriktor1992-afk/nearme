# 🔧 Исправление фильтра возраста - Пустые поля по умолчанию

## ✅ Что исправлено

### Проблема:
- Поля возраста по умолчанию заполнены значениями 14-99
- Пользователи жаловались что это неудобно
- Хотелось чтобы поля были пустыми и пользователь сам вводил возраст

### Решение:
- Изменены значения по умолчанию на `null`
- Поля ввода теперь пустые с placeholder
- Фильтрация работает корректно с пустыми значениями
- Пользователь сам вводит нужный возраст

---

## 📝 Изменения в коде

### 1. Типизация (store.ts)

**Было:**
```typescript
export interface Filters {
  gender: 'all' | 'male' | 'female';
  ageMin: number;
  ageMax: number;
  distanceMax: number;
}
```

**Стало:**
```typescript
export interface Filters {
  gender: 'all' | 'male' | 'female';
  ageMin: number | null;
  ageMax: number | null;
  distanceMax: number;
}
```

### 2. Значения по умолчанию (store.ts)

**Было:**
```typescript
filters: { gender: 'all', ageMin: 14, ageMax: 99, distanceMax: 50 }
```

**Стало:**
```typescript
filters: { gender: 'all', ageMin: null, ageMax: null, distanceMax: 50 }
```

### 3. Логика фильтрации (MapScreen.tsx)

**Было:**
```typescript
// Age filter
if (u.age < filters.ageMin || u.age > filters.ageMax) return false;
```

**Стало:**
```typescript
// Age filter
if (filters.ageMin !== null && u.age < filters.ageMin) return false;
if (filters.ageMax !== null && u.age > filters.ageMax) return false;
```

### 4. UI компоненты (FiltersPanel.tsx)

**Было:**
```tsx
<input
  type="number"
  value={filters.ageMin}
  onChange={e => {
    const val = parseInt(e.target.value);
    if (!isNaN(val) && val >= 14 && val <= 99) {
      setFilters({ ageMin: val });
    }
  }}
/>
```

**Стало:**
```tsx
<input
  type="number"
  value={localAgeMin}
  onChange={e => handleAgeMinChange(e.target.value)}
  placeholder="14"
  className="... placeholder-gray-400"
/>
```

## 🎯 Как работает фильтр

### Пустые поля (по умолчанию):
- `ageMin: null` - не фильтрует по минимальному возрасту
- `ageMax: null` - не фильтрует по максимальному возрасту
- Показываются все пользователи

### Частичное заполнение:
- Если заполнено только "От" - фильтрует по минимальному возрасту
- Если заполнено только "До" - фильтрует по максимальному возрасту

### Полное заполнение:
- Если заполнены оба поля - фильтрует по диапазону

### Логика фильтрации:
```typescript
// Если ageMin указан, проверяем минимальный возраст
if (filters.ageMin !== null && u.age < filters.ageMin) return false;

// Если ageMax указан, проверяем максимальный возраст
if (filters.ageMax !== null && u.age > filters.ageMax) return false;
```

## 🔄 Сброс фильтров

При нажатии кнопки "Сбросить":
```typescript
resetFilters: () => {
  set({ filters: { gender: 'all', ageMin: null, ageMax: null, distanceMax: 50 } });
}
```

Поля возраста возвращаются к пустым значениям.
