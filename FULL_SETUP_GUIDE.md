# ЧАСТЬ 1: УСТАНОВКА ПРОГРАММ

## 1.1 Установка Node.js

Node.js — это среда для запуска JavaScript. Без неё ничего не заработает.

### Шаг 1: Скачай Node.js
- Открой браузер
- Перейди по ссылке: **https://nodejs.org/**
- Увидишь две большие зелёные кнопки
- Нажми на **LTS** (рекомендуемую версию) — она стабильнее
- Начнётся скачивание файла `node-vXX.X.X-x64.msi` (Windows) или `.pkg` (Mac)

### Шаг 2: Установи Node.js

**На Windows:**
- Найди скачанный файл `.msi` в папке "Загрузки"
- Дважды кликни по нему
- Нажимай **"Next"** на каждом экране
- На экране "Custom Setup" оставь всё как есть → **"Next"**
- На экране "Tools for Native Modules" — **НЕ ставь галочку** → **"Next"**
- Нажми **"Install"**
- Подожди 1-2 минуты
- Нажми **"Finish"**

**На Mac:**
- Найди скачанный файл `.pkg` в папке "Загрузки"
- Дважды кликни по нему
- Нажимай **"Continue"** → **"Agree"** → **"Install"**
- Введи пароль от компьютера
- Подожди 1-2 минуты
- Нажми **"Close"**

### Шаг 3: Проверь установку

**На Windows:**
- Нажми `Win + R` (клавиша Windows + R)
- Введи `cmd` и нажми Enter
- Откроется чёрное окно — это командная строка
- Введи команду:
  ```
  node --version
  ```
- Нажми Enter
- Должно показать что-то вроде: `v20.11.0`
- Теперь введи:
  ```
  npm --version
  ```
- Должно показать: `10.2.4` (или другое число)
- Если оба числа показалися — **всё работает!** ✅

**На Mac:**
- Нажми `Cmd + Space` (откроется Spotlight)
- Введи `Terminal` и нажми Enter
- Введи те же команды:
  ```
  node --version
  npm --version
  ```
- Если числа показались — **всё работает!** ✅

# ЧАСТЬ 2: GITHUB

GitHub — это облачное хранилище для кода. Как Google Drive, но для программистов.

## 2.1 Регистрация

### Шаг 1: Создай аккаунт
- Перейди: **https://github.com/**
- Нажми **"Sign up"** (правый верхний угол)
- Введи email (свой настоящий)
- Придумай пароль (минимум 8 символов, буквы + цифры)
- Придумай username (латиницей, например: `ivan123`)
- Нажми **"Continue"**
- Пройди проверку "Я не робот"
- Введи код из письма (придёт на email)
- ✅ Аккаунт создан!

## 2.2 Создание репозитория

Репозиторий — это папка с проектом на GitHub.

### Шаг 1: Создай новый репозиторий
- На GitHub нажми на **"+"** (правый верхний угол)
- Выбери **"New repository"**

### Шаг 2: Заполни форму
- **Repository name:** `nearme` (или любое другое имя)
- **Description:** `Знакомства рядом` (необязательно)
- Выбери: **Public** (публичный)
- ✅ Поставь галочку **"Add a README file"**
- Нажми зелёную кнопку **"Create repository"**

### Шаг 3: Загрузи код проекта

Теперь нужно загрузить файлы проекта в этот репозиторий.

**Вариант А: Через веб-интерфейс (проще)**

- Ты на странице нового репозитория
- Нажми **"Add file"** → **"Upload files"**
- Перетащи ВСЕ файлы проекта в окно (или нажми "choose your files")
- Внизу напиши: `Initial commit`
- Нажми **"Commit changes"**
- Подожди пока загрузится

**Вариант Б: Через командную строку (правильнее)**

```bash
# 1. Открой терминал/командную строку
# 2. Перейди в папку с проектом:
cd путь/к/папке/nearme

# 3. Инициализируй Git:
git init

# 4. Добавь все файлы:
git add .

# 5. Сделай первый коммит:
git commit -m "Initial commit"

# 6. Подключи удалённый репозиторий:
# (замени USERNAME на свой username на GitHub)
git remote add origin https://github.com/USERNAME/nearme.git

# 7. Отправь код на GitHub:
git branch -M main
git push -u origin main
```

GitHub спросит логин и пароль:
- **Username:** твой username на GitHub
- **Password:** НЕ пароль от GitHub, а **Personal Access Token**!

### Как создать Personal Access Token:

1. На GitHub нажми на свою аватарку (правый верхний угол)
2. Выбери **"Settings"**
3. В левом меню прокрути вниз → **"Developer settings"**
4. Выбери **"Personal access tokens"** → **"Tokens (classic)"**
5. Нажми **"Generate new token"** → **"Generate new token (classic)"**
6. **Note:** `nearme` (любое описание)
7. **Expiration:** `90 days` (или `No expiration`)
8. ✅ Поставь галочку **"repo"** (полный доступ к репозиториям)
9. Нажми зелёную кнопку **"Generate token"**
10. **СКОПИРУЙ ТОКЕН** (он покажется только один раз!)
11. Используй этот токен как пароль при git push

✅ Код на GitHub!

# ЧАСТЬ 3: FIREBASE

Firebase — это база данных от Google. Здесь будут храниться пользователи и сообщения.

## 3.1 Создание проекта

### Шаг 1: Открой Firebase Console
- Перейди: **https://console.firebase.google.com/**
- Войди в свой Google аккаунт (Gmail)

### Шаг 2: Создай проект

**Экран 1: Название проекта**

- Прочти условия → поставь галочку
- Нажми **"Продолжить"**

**Экран 2: Google Analytics**
- Переключатель **"Включить Google Analytics"** → **ВЫКЛЮЧИ** (нам не нужен)
- Нажми **"Создать проект"**
- Подожди 15-30 секунд (пока создаётся)
- Появится "Новый проект готов!" → нажми **"Продолжить"**

✅ Проект Firebase создан!

## 3.2 Добавление Web-приложения

### Шаг 1: Найди кнопку
- Ты на главной странице проекта Firebase
- В центре экрана найди раздел **"Начните с добавления Firebase в приложение"**
- Там три иконки: iOS, Android, **`</>`** (Web)
- Наведи курсор на **`</>`** — появится подсказка "Web"
- Нажми на неё

### Шаг 2: Зарегистрируй приложение
- **Псевдоним приложения:** `nearme-web`
- ❌ НЕ ставь галочку "Также настроить Firebase Hosting"
- Нажми **"Зарегистрировать приложение"**

### Шаг 3: Скопируй конфигурацию ⚠️ ВАЖНО!

Появится страница с кодом. Найди блок:

```javascript
const firebaseConfig = {
  apiKey: "AIzaSyB..............................",
  authDomain: "nearme-app-xxxxx.firebaseapp.com",
  databaseURL: "https://nearme-app-xxxxx-default-rtdb.firebaseio.com",
  projectId: "nearme-app-xxxxx",
  storageBucket: "nearme-app-xxxxx.firebasestorage.app",
  messagingSenderId: "123456789012",
  appId: "1:123456789012:web:abcdef1234567890abcdef"
};
```

**СКОПИРУЙ ВЕСЬ ЭТОТ БЛОК!** (выдели мышкой от `const` до `};`)

Открой блокнот (или любой текстовый редактор) и вставь туда. Сохрани — пригодится дальше.

### Шаг 4: Заверши
- Нажми **"Далее"**
- На следующих экранах нажимай **"Пропустить эту инструкцию"**
- Ты попадёшь на главную страницу Firebase Console

# ЧАСТЬ 4: БАЗА ДАННЫХ

## 4.1 Создание Realtime Database

### Шаг 1: Найди раздел
- В левом меню Firebase Console найди раздел **"Создание"** (Build)
- Разверни его (нажми на стрелочку)
- Нажми **"Realtime Database"**

### Шаг 2: Создай базу
- Нажми синюю кнопку **"Создать базу данных"** (Create database)

### Шаг 3: Выбери регион
- Появится окно **"Настройка базы данных Cloud Firestore"**
- Нет, подожди — это Realtime Database, не Firestore
- В выпадающем списке **"Выберите местоположение"** выбери:
  - **`europe-west3 (Frankfurt)`** — ближайший к России
  - Или **`europe-west1 (Belgium)`**
- Нажми **"Далее"**

### Шаг 4: Выбери режим
- Появится окно **"Правила безопасности базы данных"**
- Выбери: ✅ **"Начать в тестовом режиме"** (Start in test mode)
- Прочитай предупреждение (для разработки это нормально)
- Нажми **"Включить"** (Enable)

✅ База данных создана!

## 4.2 Настройка правил

### Шаг 1: Открой правила
- Ты в разделе Realtime Database
- Вверху будут вкладки: **"Данные"** и **"Правила"**
- Нажми на вкладку **"Правила"** (Rules)

### Шаг 2: Замени правила
- Увидишь редактор кода с правилами по умолчанию
- **Выдели всё** (Ctrl+A или Cmd+A)
- **Удали** (Delete или Backspace)
- **Вставь** эти правила (Ctrl+V):

```json
{
  "rules": {
    "users": {
      ".read": true,
      ".write": true
    },
    "messages": {
      ".read": true,
      ".write": true
    }
  }
}
```

### Шаг 3: Сохрани
- Нажми синюю кнопку **"Опубликовать"** (Publish) вверху справа
- Появится предупреждение → нажми **"ОК"**

✅ Правила сохранены!

# ЧАСТЬ 5: TELEGRAM БОТ

## 5.1 Создание бота

### Шаг 1: Открой BotFather
- Открой Telegram
- В поиске введи: **`@BotFather`**
- Нажми на бота с синей галочкой (официальный)
- Нажми кнопку **"Запустить"** (или напиши `/start`)

### Шаг 2: Создай бота
- BotFather пришлёт список команд
- Напиши (или нажми): `/newbot`
- BotFather спросит: **"Alright, a new bot. How are we going to name it?"**
- Введи имя: **`NearMe`** (или любое другое — это отображаемое имя)
- BotFather спросит: **"Good. Now let's choose a username for your bot."**
- Введи username: **`nearme_dating_bot`**
  - ⚠️ Username ДОЛЖЕН заканчиваться на `bot`
  - ⚠️ Только латинские буквы, цифры и подчёркивания
  - Если занят — попробуй другой: `nearme_app_bot`, `nearme_love_bot` и т.д.

### Шаг 3: Сохрани токен ⚠️ ОЧЕНЬ ВАЖНО!

BotFather пришлёт сообщение:
```
Done! Congratulations on your new bot.

Use this token to access the HTTP API:
1234567890:ABCdefGHIjklMNOpqrsTUVwxyz

Keep your token secure and store it safely, it can be used by anyone to control your bot.
```

**СКОПИРУЙ ТОКЕН!** (длинная строка после "API:")
```
1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
```

Сохрани его в блокнот — он понадобится для настройки сервера бота.

✅ Бот создан!

## 5.2 Настройка описания бота

### Шаг 1: Открой настройки
- В BotFather напиши: `/mybots`
- Выбери своего бота из списка

### Шаг 2: Установи описание
- Нажми **"Bot Settings"**
- Нажми **"Description"**
- Напиши:
  ```
  NearMe — знакомства с людьми рядом с тобой в реальном времени! 💕

  📍 Находи людей на карте
  💬 Общайся в чате
  👥 Знакомься с новыми людьми
  ```
- Нажми Enter для отправки

### Шаг 3: Установи About
- Нажми **"Edit About"**
- Напиши: `Знакомства рядом с тобой 📍💕`

### Шаг 4: Установи команды
- Нажми **"Edit Commands"**
- Вставь (каждая команда с новой строки):
  ```
  start - 🚀 Открыть NearMe
  help - 📖 Помощь
  about - 💕 О приложении
  ```

### Шаг 5: Установи аватар
- Нажми **"Bot Settings"** → **"Bot Picture"**
- Отправь любую картинку (можно emoji 💕)
- Или найди в интернете красивую картинку и отправь

✅ Бот настроен!

# ЧАСТЬ 10: РЕШЕНИЕ ПРОБЛЕМ

## ❌ Проблема: "Mini App не открывается"

### Причина 1: Неправильный URL
**Решение:**
- Проверь URL в настройках бота
- Открой URL в обычном браузере — работает?
- Убедись что URL начинается с `https://` (не `http://`)

### Причина 2: Приложение не задеплоено
**Решение:**
- Зайди на Vercel → проверь что проект активен
- Попробуй redeploy: Deployments → ⋮ → Redeploy

### Причина 3: Кеш Telegram
**Решение:**
- Закрой Telegram полностью
- Открой заново
- Попробуй ещё раз

## ❌ Проблема: "Не вижу других пользователей"

### Причина 1: Firebase не настроен
**Решение:**
- Проверь `src/firebase.ts` — правильный ли конфиг?
- Открой Firebase Console → Realtime Database → Данные
- Видишь ли ты там записи?

### Причина 2: Оба пользователя не онлайн
**Решение:**
- Убедись что оба открыли приложение
- Подожди 5-10 секунд
- Обновите страницу (потяни вниз)

### Причина 3: Слишком далеко друг от друга
**Решение:**
- По умолчанию видны люди в радиусе 50 км
- Если вы в разных городах — не увидите друг друга
- Для теста можно быть в одном месте

## ❌ Проблема: "Не работает геолокация"

### Причина 1: Не разрешил доступ
**Решение:**
- Настройки телефона → Приложения → Telegram → Разрешения → Местоположение → Разрешить

### Причина 2: GPS выключен
**Решение:**
- Включи GPS/геолокацию на телефоне
- Или включи WiFi (определяет по сетям)

### Причина 3: Браузер не поддерживает
**Решение:**
- Обнови Telegram до последней версии
- Попробуй другой браузер

## ❌ Проблема: "Сообщения не приходят"

### Причина 1: Firebase Realtime Database не включена
**Решение:**
- Открой Firebase Console
- Убедись что Realtime Database создана
- Проверь правила (должны быть "true")

### Причина 2: Нет интернета
**Решение:**
- Проверь подключение к интернету
- Попробуй открыть любой сайт

### Причина 3: Ошибка в коде
**Решение:**
- Открой консоль браузера (F12)
- Посмотри красные ошибки
- Пересобери проект: `npm run build`
- Заредеплой на Vercel

## ❌ Проблема: "Карта не загружается"

### Причина 1: Нет интернета
**Решение:** Проверь подключение

### Причина 2: OpenStreetMap недоступен
**Решение:** Подожди или попробуй позже

### Причина 3: Блокировка
**Решение:** Попробуй VPN

## ❌ Проблема: "Красный экран / ошибка"

### Решение:
1. Открой консоль браузера (F12)
2. Посмотри текст ошибки
3. Скопируй ошибку
4. Погугли или напиши мне
