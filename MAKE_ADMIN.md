# 🔐 Как сделать @loriktor админом

## Способ 1: Через консоль браузера (самый быстрый)

### Шаг 1: Откройте приложение
Откройте ваше приложение в браузере и войдите как @loriktor

### Шаг 2: Откройте консоль
Нажмите **F12** (или Ctrl+Shift+I / Cmd+Option+I на Mac)

### Шаг 3: Перейдите на вкладку Console
Вверху будут вкладки: Elements, Console, Sources, Network...
Нажмите на вкладку **Console**

### Шаг 4: Вставьте эту команду:

```javascript
localStorage.setItem('nearme_admin', 'true'); location.reload();
```

### Шаг 5: Нажмите Enter
Страница перезагрузится и у вас появятся права администратора!

---

## Способ 2: Через Firebase Console (если хотите навсегда)

### Шаг 1: Откройте Firebase Console
Перейдите на https://console.firebase.google.com/

### Шаг 2: Выберите ваш проект
Найдите проект **nearme-app-59aa5**

### Шаг 3: Откройте Realtime Database
В левом меню нажмите **Realtime Database**

### Шаг 4: Найдите пользователя @loriktor
В дереве данных найдите:
```
users/
  user_xxxxx/
    name: "Ваше имя"
    ...
```

### Шаг 5: Добавьте поле isAdmin
Нажмите на пользователя и добавьте новое поле:
- **Name**: `isAdmin`
- **Value**: `true`
- **Type**: `boolean`

### Шаг 6: Нажмите "Update"

---

## Способ 3: Автоматический (рекомендую!)

### Очистите данные и зарегистрируйтесь заново:

1. Откройте приложение
2. Нажмите **F12** → вкладка **Application**
3. В левом меню найдите **Local Storage** → ваш домен
4. Нажмите правой кнопкой → **Clear** (Очистить)
5. Обновите страницу (**F5**)
6. Зарегистрируйтесь заново как @loriktor
7. **Автоматически получите права админа!** (если вы первый пользователь)

## 🎯 Быстрая команда для копирования:

```javascript
localStorage.setItem('nearme_admin', 'true'); location.reload();
```

Просто скопируйте эту команду, вставьте в консоль (F12 → Console) и нажмите Enter!

## ✅ Проверка прав:

После выполнения команды:
1. В правом верхнем углу должна появиться иконка **щита 🛡️**
2. Нажмите на неё
3. Откроется админ-панель с полной статистикой
