# 🗺️ Кнопка "НА КАРТУ"

## ✨ Что добавлено

Добавлена заметная кнопка **"НА КАРТУ"** в левом нижнем углу карты.

### Расположение
- **Позиция:** Внизу слева, под кнопками списка пользователей и фильтров
- **Стиль:** Градиентный фон (фиолетовый → розовый)
- **Иконка:** 🗺️ Карта с маркерами
- **Текст:** "НА КАРТУ" жирным белым шрифтом

### Функциональность
При нажатии на кнопку:
- ✅ Карта центрируется на вашем текущем местоположении
- ✅ Использует GPS координаты пользователя
- ✅ Плавное перемещение карты
- ✅ Обновление позиции маркера

### Когда использовать
- Когда вы переместились по карте и хотите вернуться к себе
- При повторном входе в приложение
- Для быстрой навигации к своему местоположению

## 🔧 Технические детали

### Изменённые файлы
- `src/components/MapScreen.tsx` - добавлена кнопка

### Логика работы
```typescript
onClick={() => {
  if (currentUser) {
    setCenterLat(currentUser.lat);
    setCenterLng(currentUser.lng);
  }
}}
```

1. Проверяет наличие текущего пользователя
2. Получает его координаты из `currentUser.lat` и `currentUser.lng`
3. Устанавливает центр карты на эти координаты
4. Карта плавно перемещается к новому центру

### Отличие от кнопки GPS (🎯)
- **Кнопка "НА КАРТУ"** - использует сохраненные координаты пользователя
- **Кнопка GPS (🎯)** - запрашивает новые координаты через `navigator.geolocation`
