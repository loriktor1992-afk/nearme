# 🎨 Обновление профилей и приватности

## ✨ Что нового

### 1. 📸 Полный профиль пользователя

При просмотре профиля другого пользователя теперь отображается **вся информация**:

- **Главное фото** - большое фото профиля
- **Галерея фотографий** - все загруженные фото (до 30 штук)
- **Имя и возраст** - с возможностью верификации
- **Статус** - короткое описание настроения
- **Расстояние** - сколько метров до пользователя (если разрешено)
- **Биография** - подробная информация о себе
- **Кого ищет** - цели знакомства
- **Интересы** - теги с интересами
- **Языки** - какие языки знает
- **Дополнительная информация**:
  - Город
  - Дата рождения и знак зодиака
  - Время активности
  - Уровень пользователя
  - Рост (если указан)

### 2. 🔒 Расширенные настройки приватности

Добавлены **три режима видимости**:

#### 🟢 Я онлайн
- Пользователь виден на карте
- Другие видят ваше местоположение
- Стандартный режим

#### ⚫ Скрыт
- Пользователь пользуется приложением
- **Никто не видит** вас на карте
- Вы можете просматривать других, но вас не видно
- Идеально для приватного использования

#### 👻 Призрачный режим (Premium)
- Можно видеть людей на карте
- **Не показывает** себя другим
- Полная анонимность
- **Будущая монетизация** - Premium функция

### 3. ⚙️ Полные настройки приватности

В разделе "Приватность" теперь можно настроить:

**Режим видимости:**
- 🟢 Онлайн
- ⚫ Скрыт
- 👻 Призрачный (Premium)

**Настройки карты:**
- ✅ Показываться на карте (вкл/выкл)
- 📏 Радиус видимости (1-50 км)
  - Настраивается ползунком
  - Показывает расстояние в километрах

**Настройки общения:**
- 💬 Разрешить сообщения (вкл/выкл)
- 📍 Показывать расстояние (вкл/выкл)
- ⏰ Показывать время активности (вкл/выкл)

**Безопасность:**
- 🚫 Заблокированные пользователи
  - Список заблокированных
  - Возможность разблокировать

### 4. 🗺️ Исправление слипающихся маркеров

**Проблема:** Когда несколько пользователей находились в одном месте, их маркеры слипались на карте.

**Решение:** Добавлена функция `calculateMarkerOffset`, которая:
- Проверяет расстояние между пользователями
- Если расстояние < 50 метров, добавляет смещение
- Смещение рассчитывается по золотому углу (137.5°) для равномерного распределения
- Маркеры не слипаются и все видны

## 📱 Как использовать

### Просмотр полного профиля

1. Нажмите на маркер пользователя на карте
2. В всплывающем окне нажмите **"Открыть профиль"**
3. Откроется полный профиль со всей информацией
4. Можно листать фотографии, смотреть интересы и т.д.

### Настройка приватности

1. Откройте свой профиль (нажмите на свой аватар)
2. Перейдите на вкладку **"Приватность"**
3. Нажмите **"Расширенные настройки приватности"**
4. Выберите режим видимости:
   - 🟢 Онлайн - виден всем
   - ⚫ Скрыт - не виден на карте
   - 👻 Призрачный - видите других, вас не видят (Premium)
5. Настройте радиус видимости (1-50 км)
6. Включите/выключите показ на карте
7. Настройте кто может писать сообщения
8. Нажмите **"Сохранить"**

### Блокировка пользователей

1. Откройте профиль пользователя
2. Нажмите на три точки (⋮) в правом верхнем углу
3. Выберите **"Заблокировать"**
4. Пользователь добавится в список заблокированных
5. Он больше не сможет писать вам и видеть ваш профиль

В `listenForUsers` добавлена фильтрация по режиму приватности:

```typescript
const onlineUsers: User[] = allUsers
  .filter(u => u.id !== get().currentUser?.id)
  .filter(u => Date.now() - u.lastSeen < 30 * 60 * 1000)
  .filter(u => {
    // Учитываем режим приватности
    const privacyMode = u.privacySettings?.visibilityMode || 'online';
    return privacyMode === 'online' || privacyMode === 'ghost';
  })
  .filter(u => {
    // Учитываем showOnMap
    return u.privacySettings?.showOnMap !== false;
  });
```

### Расчет смещения маркеров

```typescript
const calculateMarkerOffset = (users: User[], index: number) => {
  const user = users[index];
  let offsetLat = 0;
  let offsetLng = 0;
  
  for (let i = 0; i < users.length; i++) {
    if (i === index) continue;
    
    const otherUser = users[i];
    const distance = getDistance(user.lat, user.lng, otherUser.lat, otherUser.lng);
    
    if (distance < 50) {
      const angle = (index * 137.5) % 360;
      const offsetDistance = 0.0002;
      
      offsetLat = Math.cos(angle * Math.PI / 180) * offsetDistance;
      offsetLng = Math.sin(angle * Math.PI / 180) * offsetDistance;
      
      break;
    }
  }
  
  return {
    lat: user.lat + offsetLat,
    lng: user.lng + offsetLng,
  };
};
```
