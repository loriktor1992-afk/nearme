# 📬 Система Push-уведомлений и сохранение чатов

## ✨ Что нового

### 1. 💬 Чаты сохраняются даже когда собеседник оффлайн

**Проблема:** Раньше чаты исчезали когда пользователь выходил из онлайна.

**Решение:**
- Все сообщения теперь сохраняются в **Firebase Realtime Database**
- Чаты загружаются из Firebase при каждом входе в приложение
- Дополнительно сохраняются в **localStorage** для оффлайн режима
- История чатов доступна даже когда собеседник не в сети

**Как это работает:**
```typescript
// Сообщения загружаются из Firebase
listenForMessages() {
  // 1. Сначала загружаем из localStorage (если есть)
  const savedMessages = localStorage.getItem(`nearme_messages_${userId}`);
  
  // 2. Затем подписываемся на Firebase
  onValue(messagesRef, (snapshot) => {
    // 3. Обновляем localStorage
    localStorage.setItem(`nearme_messages_${userId}`, JSON.stringify(messages));
  });
}
```

### 2. 🔔 Push-уведомления

Добавлена полноценная система push-уведомлений через **Telegram Web App API**.

#### Типы уведомлений:

**💬 Новое сообщение**
- Уведомление когда кто-то пишет вам
- Показывает имя отправителя и текст сообщения
- При клике открывает чат с отправителем

**❤️ Новый лайк**
- Уведомление когда кто-то лайкнул ваш профиль
- Показывает имя пользователя

**💕 Взаимная симпатия (Match)**
- Уведомление когда у вас взаимный лайк
- Красивое popup-окно с анимацией
- При клике открывает профиль пользователя

**🔔 Системные уведомления**
- Важные системные сообщения
- Обновления приложения

#### Как работают уведомления:

1. **Telegram API**
   - Вибрация через `HapticFeedback`
   - Popup-окна через `showPopup()`
   - Alert-окна через `showAlert()`

2. **Локальное хранение**
   - Все уведомления сохраняются в localStorage
   - Хранятся последние 50 уведомлений
   - Можно просмотреть историю в панели уведомлений

3. **Визуальные индикаторы**
   - Красный бейдж с количеством непрочитанных
   - Иконка колокольчика 🔔 в верхней панели
   - Цветовая кодировка по типу уведомления

### 3. 📋 Панель уведомлений

Новый компонент **NotificationsPanel** с полным функционалом:

**Возможности:**
- Просмотр всех уведомлений
- Фильтрация по типу (сообщения, лайки, match, системные)
- Пометка как прочитанное при клике
- Быстрый переход к чату или профилю
- Удаление всех уведомлений
- Цветовая кодировка по типу

**Дизайн:**
- Иконки для каждого типа уведомления
- Цветовая схема:
  - 💬 Синий - сообщения
  - ❤️ Розовый - лайки
  - 💕 Фиолетовый - match
  - 🔔 Серый - системные
- Непрочитанные уведомления выделены边框

## 💾 Сохранение чатов

### Как это работает:

1. **Firebase Realtime Database**
   - Все сообщения сохраняются в Firebase
   - Доступны с любого устройства
   - Синхронизация в реальном времени

2. **localStorage**
   - Дополнительное кэширование
   - Работает в оффлайн режиме
   - Быстрая загрузка при старте

3. **Структура данных:**
   ```
   Firebase:
   messages/
     messageId1/
       fromId: "user1"
       toId: "user2"
       text: "Привет!"
       timestamp: 1234567890
       read: false
   
   localStorage:
   nearme_messages_userId = [
     { id, fromId, toId, text, timestamp, read }
   ]
   ```

### Преимущества:

✅ Чаты не исчезают когда собеседник оффлайн  
✅ История сохраняется навсегда  
✅ Работает в оффлайн режиме  
✅ Быстрая загрузка из кэша  
✅ Синхронизация между устройствами

## 🎯 Особенности реализации

### Push-уведомления в Telegram:

**Ограничения:**
- Работают только в Telegram Mini App
- Требуют разрешения от пользователя
- Ограниченный набор методов API

**Решения:**
- Используем `showPopup()` для важных уведомлений (match)
- Используем `showAlert()` для обычных уведомлений
- Используем `HapticFeedback` для вибрации
- Дублируем в локальную панель уведомлений

### Оффлайн режим:

**Что работает оффлайн:**
- Просмотр сохранённых чатов
- Просмотр профиля
- История уведомлений

**Что не работает оффлайн:**
- Отправка новых сообщений
- Получение новых уведомлений
- Обновление данных пользователей
