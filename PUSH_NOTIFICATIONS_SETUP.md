# 🔔 Настройка Push-уведомлений через Telegram Bot

## 📋 Что нужно сделать

Для отправки push-уведомлений когда приложение закрыто, но Telegram открыт, нужно:

1. ✅ Настроить Firebase Cloud Functions
2. ✅ Получить токен Telegram бота
3. ✅ Задеплоить функции на Firebase
4. ✅ Протестировать уведомления

---

## 🚀 Шаг 1: Установка Firebase CLI

### На компьютере:

```bash
# Установите Firebase CLI глобально
npm install -g firebase-tools

# Войдите в Firebase
firebase login

# Инициализируйте Functions в проекте
firebase init functions
```

### При инициализации выберите:
- ✅ Use an existing project (выберите ваш проект nearme-app-59aa5)
- ✅ JavaScript (не TypeScript для простоты)
- ✅ No для ESLint
- ✅ Yes для установки зависимостей

---

## 🔑 Шаг 2: Получение токена Telegram бота

### Если у вас уже есть бот:

1. Откройте @BotFather в Telegram
2. Отправьте команду `/mybots`
3. Выберите вашего бота
4. Нажмите "API Token"
5. Скопируйте токен (формат: `123456789:ABCdefGHI...`)

### Если нет бота:

1. Откройте @BotFather в Telegram
2. Отправьте `/newbot`
3. Следуйте инструкциям
4. Скопируйте полученный токен

---

## ⚙️ Шаг 3: Настройка Firebase Functions

### 3.1 Откройте файл `functions/index.js`

### 3.2 Замените токен бота:

Найдите строку:
```javascript
const TELEGRAM_BOT_TOKEN = 'YOUR_BOT_TOKEN_HERE';
```

Замените на ваш токен:
```javascript
const TELEGRAM_BOT_TOKEN = '123456789:ABCdefGHI...'; // Ваш токен
```

### 3.3 Сохраните файл

---

## 📦 Шаг 4: Установка зависимостей

```bash
# Перейдите в папку functions
cd functions

# Установите зависимости
npm install
```

---

## 🚀 Шаг 5: Деплой Functions

```bash
# Вернитесь в корень проекта
cd ..

# Задеплойте функции на Firebase
firebase deploy --only functions
```

### Что произойдет:
- Firebase загрузит ваш код
- Создаст Cloud Functions
- Активирует триггеры для базы данных
- Функции начнут работать автоматически

---

## ✅ Шаг 6: Проверка работы

### 6.1 Откройте приложение в Telegram

### 6.2 Откройте консоль браузера (F12)

### 6.3 Найдите сообщение:
```
📱 Telegram chat_id сохранен: 123456789
```

Это значит что chat_id сохранен в Firebase и уведомления будут работать!

### 6.4 Протестируйте уведомления:

1. **Попросите друга написать вам сообщение**
   - Вы должны получить уведомление через бота
   - Даже если приложение закрыто!

2. **Попросите друга лайкнуть ваш профиль**
   - Вы получите уведомление "❤️ [Имя] лайкнул(а) ваш профиль!"

3. **Взаимный лайк**
   - Оба пользователя получат уведомление "💕 Взаимная симпатия!"

## 🔧 Как это работает

### Архитектура:

```
Пользователь A отправляет сообщение
         ↓
Firebase Realtime Database сохраняет сообщение
         ↓
Cloud Function срабатывает (onMessageCreated)
         ↓
Функция читает telegramChatId получателя из Firebase
         ↓
Отправляет уведомление через Telegram Bot API
         ↓
Пользователь B получает сообщение от бота
```

### Триггеры:

1. **onMessageCreated** - при новом сообщении
   - Отправляет: "💬 Новое сообщение от [Имя]"

2. **onLikeCreated** - при новом лайке
   - Отправляет: "❤️ [Имя] лайкнул(а) ваш профиль!"

3. **onMatchCreated** - при взаимном лайке
   - Отправляет: "💕 Взаимная симпатия с [Имя]!"

## 💰 Стоимость Firebase Functions

### Бесплатный план (Spark):
- 125,000 вызовов функций в месяц
- 400,000 ГБ-сек памяти
- 200,000 секунд CPU времени

### Для вашего приложения:
- ~1000 пользователей × 10 сообщений в день = 10,000 вызовов/день
- 10,000 × 30 дней = 300,000 вызовов/месяц
- **Это больше бесплатного лимита!**

### Решение:
- Перейти на платный план (Blaze) - ~$5-10/месяц
- Или оптимизировать функции (кэширование, батчинг)

## 🔒 Безопасность

### Что защищено:
- ✅ Токен бота хранится только в Cloud Functions
- ✅ Пользователи не видят токен
- ✅ Firebase проверяет права доступа

### Что нужно сделать:
- ⚠️ НЕ коммитьте `functions/index.js` с токеном в Git
- ⚠️ Добавьте `functions/` в `.gitignore`
- ⚠️ Используйте Firebase Secrets для хранения токена

### Использование Firebase Secrets:

```bash
# Установите секрет
firebase functions:secrets:set TELEGRAM_BOT_TOKEN
# Введите ваш токен

# Используйте в коде
const TELEGRAM_BOT_TOKEN = process.env.TELEGRAM_BOT_TOKEN;
```

## 🐛 Решение проблем

### Проблема: Уведомления не приходят

**Решение:**
1. Проверьте что chat_id сохранен в Firebase
2. Проверьте логи Functions: `firebase functions:log`
3. Убедитесь что бот активен
4. Проверьте что пользователь не заблокировал бота

### Проблема: Ошибка "Missing telegramChatId"

**Решение:**
1. Пользователь должен открыть приложение хотя бы один раз
2. При открытии chat_id автоматически сохраняется
3. Проверьте Firebase Console → Realtime Database → users → [userId] → telegramChatId

### Проблема: Functions не деплоятся

**Решение:**
1. Убедитесь что установлен Firebase CLI: `npm install -g firebase-tools`
2. Войдите в Firebase: `firebase login`
3. Проверьте что выбран правильный проект: `firebase use --add`
