# 🔔 Push-уведомления - Краткая инструкция

## ✅ Что сделано

Добавлена система push-уведомлений через Firebase Cloud Functions + Telegram Bot API.

**Теперь уведомления приходят даже когда:**
- ✅ Приложение закрыто
- ✅ Telegram открыт
- ✅ Пользователь не в приложении

---

## 🚀 Быстрая настройка (10 минут)

### 1. Установите Firebase CLI
```bash
npm install -g firebase-tools
firebase login
```

### 2. Инициализируйте Functions
```bash
firebase init functions
# Выберите: Use existing project → nearme-app-59aa5
# Выберите: JavaScript
# Выберите: No для ESLint
```

### 3. Получите токен бота
- Откройте @BotFather в Telegram
- `/mybots` → выберите бота → API Token
- Скопируйте токен

### 4. Вставьте токен в functions/index.js
```javascript
const TELEGRAM_BOT_TOKEN = 'ВАШ_ТОКЕН_ЗДЕСЬ';
```

### 5. Установите зависимости
```bash
cd functions
npm install
cd ..
```

### 6. Задеплойте функции
```bash
firebase deploy --only functions
```

### 7. Готово! ✅

---

## 📱 Как это работает

1. Пользователь открывает Mini App
2. Telegram chat_id автоматически сохраняется в Firebase
3. Когда приходит новое сообщение/лайк/матч:
   - Firebase Cloud Function срабатывает
   - Отправляет уведомление через Telegram Bot API
   - Пользователь получает сообщение от бота

---

## 🎯 Что уведомляет

| Событие | Уведомление |
|---------|-------------|
| 💬 Новое сообщение | "💬 Новое сообщение от [Имя]" |
| ❤️ Новый лайк | "❤️ [Имя] лайкнул(а) ваш профиль!" |
| 💕 Взаимный лайк | "💕 Взаимная симпатия с [Имя]!" |

---

## 💰 Стоимость

**Бесплатный план Firebase:**
- 125,000 вызовов функций/месяц
- Достаточно для ~1000 активных пользователей

**Если нужно больше:**
- Платный план Blaze: ~$5-10/месяц
- Неограниченные вызовы

## 🔒 Безопасность

⚠️ **ВАЖНО:** Не коммитьте `functions/index.js` с токеном в Git!

Файл уже добавлен в `.gitignore`.

Для большей безопасности используйте Firebase Secrets:
```bash
firebase functions:secrets:set TELEGRAM_BOT_TOKEN
```
