# 🗺️ NearMe - Telegram Mini App для знакомств

Приложение для знакомств с людьми рядом в реальном времени. Работает как Telegram Mini App.

## ✨ Возможности

### 📍 Карта и геолокация
- Интерактивная карта OpenStreetMap
- Отображение пользователей рядом в реальном времени
- GPS-трекинг местоположения
- Фильтры по расстоянию

### 💬 Чат
- Мгновенные сообщения
- Реакции на сообщения (👍 ❤️ 😂 😮 😢 🔥)
- Индикатор "печатает..."
- Галочки прочитано (✓ / ✓✓)
- Относительное время ("2 мин назад", "вчера")
- Быстрые ответы
- Удаление чатов

### 👤 Профиль
- Загрузка фото (с автоматическим сжатием)
- Галерея до 30 фотографий
- Полная информация (рост, дата рождения, знак зодиака)
- Интересы и языки
- Социальные сети
- Настройки приватности
- Статистика (лайки, просмотры, уровень)

### 🏘️ Районы
- Создание тематических районов
- Система админов
- Приглашения участников
- Управление участниками

### ❤️ Взаимодействие
- Лайки пользователей
- Взаимные симпатии (Match)
- Уведомления о взаимных лайках
- Просмотры профилей

### 🎨 UI/UX
- Тёмная/светлая тема
- Адаптивный дизайн
- Плавные анимации
- Свайп для навигации по фото
- Счётчик непрочитанных сообщений

## 🛠 Технологии

- **Frontend:** React 18 + TypeScript + Vite
- **State Management:** Zustand
- **Database:** Firebase Realtime Database
- **Maps:** Leaflet + OpenStreetMap
- **Styling:** Tailwind CSS
- **Icons:** Font Awesome
- **Platform:** Telegram Web App SDK

## 📦 Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/yourusername/nearme.git
cd nearme
```

2. Установите зависимости:
```bash
npm install
```

3. Создайте файл `.env` на основе `.env.example`:
```bash
cp .env.example .env
```

4. Заполните `.env` вашими Firebase credentials:
```
VITE_FIREBASE_API_KEY=your_api_key
VITE_FIREBASE_AUTH_DOMAIN=your-project.firebaseapp.com
VITE_FIREBASE_DATABASE_URL=https://your-project-default-rtdb.firebaseio.com
VITE_FIREBASE_PROJECT_ID=your-project-id
VITE_FIREBASE_STORAGE_BUCKET=your-project.appspot.com
VITE_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
VITE_FIREBASE_APP_ID=your_app_id
```

5. Запустите dev-сервер:
```bash
npm run dev
```

## 🚀 Деплой

### Vercel (рекомендуется)

1. Загрузите код на GitHub
2. Подключите репозиторий к Vercel
3. Добавьте переменные окружения в настройках Vercel
4. Деплой начнётся автоматически

### Настройка Telegram Bot

1. Создайте бота через [@BotFather](https://t.me/BotFather)
2. Получите токен бота
3. Настройте Menu Button:
   - `/mybots` → выберите бота → `Bot Settings` → `Menu Button` → `Edit Menu Button URL`
   - Вставьте URL вашего задеплоенного приложения
   - Укажите название кнопки (например, "Открыть NearMe 💕")

## 🔒 Безопасность

### Firebase Rules

Настройте правила безопасности в Firebase Console:

```json
{
  "rules": {
    "users": {
      ".read": true,
      ".write": "auth != null"
    },
    "messages": {
      ".read": "auth != null",
      ".write": "auth != null"
    },
    "districts": {
      ".read": true,
      ".write": "auth != null"
    },
    "invites": {
      ".read": "auth != null",
      ".write": "auth != null"
    }
  }
}
```

### Переменные окружения

⚠️ **Никогда не коммитьте файл `.env` в репозиторий!**

Добавьте `.env` в `.gitignore`:
```
.env
.env.local
.env.*.local
```

## 📱 Использование

### Регистрация
1. Откройте бота в Telegram
2. Нажмите "Открыть NearMe 💕"
3. Заполните профиль (имя, возраст, пол, био)
4. Разрешите доступ к геолокации

### Основные функции
- **Карта:** Видите пользователей рядом
- **Фильтры:** Настраивайте пол, возраст, расстояние
- **Профиль:** Нажмите на свой аватар для редактирования
- **Чаты:** Нажмите на иконку 💬 для списка чатов
- **Районы:** Нажмите на иконку 🗺️ для управления районами

## 🎯 Особенности реализации

### Сжатие изображений
Все загружаемые изображения автоматически сжимаются:
- Аватар: до 800x800px, качество 70%, макс 1MB
- Фото в галерее: до 1200x1200px, качество 80%, макс 2MB

### Rate Limiting
- Загрузка фото: максимум 10 загрузок в минуту
- Отправка сообщений: защита от спама

### Кэширование
- Тема сохраняется в localStorage
- Фильтры сохраняются в localStorage
- Сессия пользователя восстанавливается при перезагрузке

### Обработка ошибок
- ErrorBoundary для критических ошибок
- Логирование ошибок в консоль
- Понятные сообщения об ошибках для пользователя

## 📊 Производительность

- **Оптимизация рендеринга:** useMemo для фильтрации пользователей
- **Ленивая загрузка:** Данные загружаются по необходимости
- **Сжатие данных:** Изображения сжимаются перед загрузкой
- **Минимальные запросы:** Используются Firebase listeners вместо polling

## 🌍 Масштабируемость

Текущие лимиты (бесплатный план Firebase):
- 100 одновременных подключений
- 10 GB/месяц трафика
- 1 GB хранилище

Для масштабирования:
1. Перейдите на платный план Firebase
2. Добавьте пагинацию для сообщений
3. Используйте Firebase Cloud Functions
4. Добавьте CDN для статических файлов
