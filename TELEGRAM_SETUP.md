# 🤖 СОЗДАНИЕ TELEGRAM MINI APP "NEARME"

## 📋 Что нужно:
- Telegram аккаунт
- Хостинг для приложения (бесплатный)
- 15-20 минут времени

---

## 🚀 ШАГ 1: Создание Telegram бота

### 1.1 Открой BotFather
- В Telegram найди бота: **@BotFather**
- Или перейди по ссылке: https://t.me/BotFather
- Нажми **"Запустить"** (или напиши `/start`)

### 1.2 Создай нового бота
- Напиши команду: `/newbot`
- BotFather спросит имя бота
- Введи имя: **NearMe** (или любое другое)
- Теперь нужно придумать username
- Username должен заканчиваться на `bot`
- Пример: `nearme_dating_bot` или `nearme_app_bot`
- Если username занят, попробуй другой

### 1.3 Сохрани токен бота
- После создания BotFather даст тебе **токен**
- Он выглядит так: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`
- **ВАЖНО:** Сохрани его в надёжном месте!
- Токен нужен для настройки Mini App

### 1.4 Настрой бота
- Напиши BotFather: `/mybots`
- Выбери своего бота
- Нажми **"Bot Settings"**
- Нажми **"Menu Button"**
- Нажми **"Configure menu button"**
- Выбери своего бота
- Введи URL твоего приложения (см. ШАГ 3)
- Введи название кнопки: **Открыть NearMe**

✅ **Бот создан!**

## 📦 ШАГ 3: Деплой приложения

### Вариант A: Vercel (рекомендуется, бесплатно)

#### 3.1 Зарегистрируйся на Vercel
- Перейди: https://vercel.com/
- Войди через GitHub

#### 3.2 Загрузи проект на GitHub
```bash
# В папке проекта
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/ТВОЙ_USERNAME/nearme.git
git push -u origin main
```

#### 3.3 Импортируй проект в Vercel
- На Vercel нажми **"New Project"**
- Выбери свой репозиторий `nearme`
- Vercel автоматически определит настройки
- Нажми **"Deploy"**
- Подожди 1-2 минуты

#### 3.4 Получи URL
- После деплоя Vercel даст URL типа:
  `https://nearme.vercel.app`
- Это и есть URL твоего Mini App!

### Вариант B: Netlify (тоже бесплатно)

#### 3.1 Зарегистрируйся на Netlify
- Перейди: https://netlify.com/
- Войди через GitHub

#### 3.2 Загрузи проект
- Нажми **"Add new site"** → **"Import an existing project"**
- Выбери GitHub репозиторий
- Build command: `npm run build`
- Publish directory: `dist`
- Нажми **"Deploy site"**

#### 3.3 Получи URL
- URL типа: `https://nearme.netlify.app`

### Вариант C: GitHub Pages (бесплатно)

```bash
# Установи gh-pages
npm install -D gh-pages

# Добавь в package.json (в scripts):
"predeploy": "npm run build",
"deploy": "gh-pages -d dist"

# Запусти деплой
npm run deploy
```

URL будет: `https://ТВОЙ_USERNAME.github.io/nearme/`

## 🐛 ЧАСТЫЕ ПРОБЛЕМЫ

### Проблема: "Бот не отвечает"
**Решение:**
- Проверь, что бот запущен (нажми /start)
- Убедись, что URL правильный
- Проверь, что приложение задеплоено

### Проблема: "Mini App не открывается"
**Решение:**
- Проверь URL в настройках бота
- Убедись, что HTTPS (не HTTP)
- Проверь консоль браузера на ошибки

### Проблема: "Не работает геолокация"
**Решение:**
- В Telegram Mini App геолокация работает через браузер
- Пользователь должен разрешить доступ
- Некоторые устройства могут не поддерживать

### Проблема: "Карта не загружается"
**Решение:**
- Проверь интернет-соединение
- OpenStreetMap может быть заблокирован
- Попробуй другой tile provider
